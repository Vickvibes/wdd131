Naija Side Hustle Hub

Website Planning Document

Site Name

Naija Side Hustle Hub — This name identifies the website as a practical Nigerian resource for discovering and starting online income opportunities.

Possible domain: naijasidehustles.ng

Site Purpose

The website will provide Nigerian youth with clear guides to legitimate online business ideas and side hustles. It will explain startup requirements, skill needs, expected costs, and useful links so visitors can choose and begin an opportunity with confidence.

Scenarios

  • Which low-cost online side hustle can I start this month using only a phone and internet connection?
  • Where can I find a practical guide, trusted resources, and a checklist for becoming a freelance graphic designer?

Color Scheme

#1F5A3A Primary green — header and section accents
#D97941 Warm accent — calls to action and highlights
#242E29 Dark text — headings and body copy
#FAF8F5 Page background — warm neutral surface

Typography

Lora will be used for headings to create a trustworthy, established appearance.

DM Sans will be used for body text, navigation, cards, and controls because it is clear and accessible on mobile screens.
